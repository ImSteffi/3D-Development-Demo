3D Viewer

Majuta kogu viewer-kaust oma veebiserveris. Kopeeri allolev kood oma veebilehele ja muuda IFRAME-i src oma serveris asuva viewer/index.html aadressiks. Hoia kausta failid ja alamkaustad koos.

Raami suurust ja stiile muuda oma veebilehe CSS-is. Viewer'i nuppude ja paneelide värve saad muuta failis viewer/theme.css.

Host the entire viewer folder on your web server. Copy the code below into your webpage and change the iframe src to the URL of viewer/index.html on your server. Keep its files and subfolders together.

Adjust the frame's size and styling in your website CSS. Edit viewer/theme.css to change the viewer's button and panel colours.

Copy to your page

<iframe
  class="project-viewer"
  src="/3d/viewer/index.html"
  title="Interactive 3D view"
  loading="lazy"
  allow="fullscreen; xr-spatial-tracking"
  allowfullscreen>
</iframe>

<style>
.project-viewer {
  display: block;
  width: 100%;
  height: 600px;
  border: 0;
  border-radius: 16px;
}
</style>
